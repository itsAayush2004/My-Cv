# Example C: Short/Reel, "Mehmaan Aa Rahe Hain" (30 s)

```
MODE:        C (Short)          LENGTH: 30 s       HEAT LEVEL: 0 Clean
PREMISE:     When guests are arriving, Mummy turns the house into a five-star
             hotel, until the guests cancel and everything snaps back.
CAST:        MUMMY (Pressure) · BETA (Straight)
```

| Time | Beat | Character | Line / Action |
|---|---|---|---|
| 0 to 2 s | Hook | MUMMY *(caption: "When guests call")* | Mehmaan aa rahe hain! 10 minute! |
| 2 to 6 s | Setup | (fast montage, speed ramp: sofa cover changed, showpiece unwrapped, "guest wale" cups out of the cupboard) | |
| 6 to 10 s | | MUMMY | Woh wale biscuit nikalo. Jo hum nahi khaate. |
| 10 to 14 s | | BETA *(reaching for one)* | (hand slapped away. SFX: slap) |
| 14 to 20 s | Turn | MUMMY *(on phone)* | Arre nahi aa rahe? Koi baat nahi didi, phir kabhi. |
| 20 to 26 s | | (reverse montage: everything goes back in, the biscuits get locked away) | |
| 26 to 30 s | Tag | BETA *(to camera, holding one smuggled biscuit)* | Agli baar main hi call karunga. Unke number se. |

**Devices used:** verbatim line ("Jo hum nahi khaate"), status flip (hotel → normal), reverse-montage loop, tag with a second laugh. Works on mute because of captions.
