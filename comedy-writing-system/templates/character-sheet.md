# Character Sheet

Fill one in for every recurring character. If you can't fill in **Real source** and **Fingerprint**, the character isn't ready.

| Field | Fill in |
|---|---|
| **Name** | |
| **Slot** | Straight / Deadpan / Naive / Loud / Pressure / Rival |
| **Real source** | Which real person is this built from? (Bhuvan built Titu Mama from his own uncle.) |
| **The one trait (turned up to 11)** | |
| **Want** | What do they always want in a scene? |
| **Fear / weak spot** | What makes them lose status? |
| **Fingerprint** | Signature word, sound or sentence shape |
| **Language mix** | % Hindi / % English, and when they switch |
| **Tempo** | Slow / normal / fast-talker |
| **Default reaction** | What they do when someone else says something shocking |
| **Never says** | Words or tones that would break the character |
| **Costume shorthand** | One prop, readable in 0.5 s |
| **Best pairings** | Who they clash with, and what kind of scene that makes |

## Voice test
Write the **same line of meaning** in this character's voice, e.g. *"Dinner is ready."*

> **This character:** ...

If it sounds like any other character's version, rewrite the fingerprint.
