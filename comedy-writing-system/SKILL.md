# Comedy Script System

Read these files from this folder before writing:
- `03-the-system.md`: the 8-stage pipeline (required)
- `04-dialogue-toolkit.md`: 18 devices and the punch-up checklist (required)
- `01-bb-ki-vines-study.md` and `02-raj-grover-study.md`: background, as needed
- `examples/`: the target quality bar

## Procedure

1. **Premise:** turn the request into *"When [CHARACTER] wants [SMALL GOAL], [OBSTACLE] makes it [ESCALATION], until [TWIST]."* Run the 3-question test (recognition, character, stakes).
2. **Mode:** A (story, 4 to 10 min), B (format sketch, 1 to 4 min) or C (short, 20 to 60 s). If the user doesn't say, default to C for "reel/short" and B otherwise.
3. **Cast:** assign the slots (Straight, Deadpan, Naive, Loud, Pressure, Rival). Give each character a fingerprint. Use the user's own characters if they have them; never use BB Ki Vines or Raj Grover character names or catchphrases.
4. **Heat level:** default to **0 Clean** unless the user asks otherwise.
5. **Write** using the script template (`templates/script-template.md`): numbered lines, written silences, delivery notes. Apply the 12 laws.
6. **Punch-up:** run the Cut, Sharpen and Add passes, then tick the punch-up checklist.
7. **Output:** the script table, 3 alt lines for the top 3 punchlines, the devices used, and the score out of 40. If it scores under 28, rewrite the weakest category before showing it.
8. If the user will shoot it solo, also produce the shoot sheet (`templates/shoot-sheet.md`).
