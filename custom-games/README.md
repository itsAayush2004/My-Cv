# 100 Custom Viral Games · ARTHIS.space Design Pack

One hundred **original** ARTHIS mini-games. Each one takes the mechanic behind a viral hit from 2020–2026 and gives it a new name, world, twist, palette and style kit, built to the ARTHIS.space house standard (instant start, no menus, max 3 inputs, a 3-stat HUD, one cohesive rounded art set).

| | |
|---|---|
| **House rules** | [ARTHIS-STYLE.md](ARTHIS-STYLE.md) |
| **Visual catalog** | [catalog.html](catalog.html): open in a browser |
| **Data** | [games.json](games.json) |
| **Regenerate** | `python3 _source/build.py` (edit `_source/data_*.py`) |

Each `DESIGN.md` has: brief table · pitch · viral hook · twist / invented rule / what we cut · core mechanic · rules · win/lose · controls · HUD + hint + sheets · difficulty · tuning · style kit · palette swatches · asset sheet · 3 background bands · juice · phone scaling · 3 feed cards · gate and test plan · paste-ready ARTHIS prompt.
